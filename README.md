# 📰 News Explorer Frontend

Welcome to the frontend of **News Explorer**, a responsive web application that allows users to search for news articles, save favorites, and manage account. This project is built with React and integrates with a backend API for authentication and article storage.

## 🚀 Features

- Search for news articles using keyword queries
- View article previews with source, date, and image
- Save and unsave articles to a personal collection
- Responsive design for desktop and mobile
- Conditional rendering based on authentication state
- Smooth dropdown menu for mobile navigation
- Buttons, inputs, and links styled for all states (hover, focus, active)
- Reusable components implemented
- Fonts connected via `@font-face` with system fallbacks
- SVG icons used throughout
- Form fields include placeholders and `required` attributes

## Tech Stack

- **React** with functional components and hooks
- **React Router** for navigation
- **CSS Modules** for scoped styling
- **RESTful API** integration for user and article management
